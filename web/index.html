Pick a commit. Get horizon-client.exe.

Builds Horizon for Windows x64 on GitHub's runners, from the exact revision you choose, the way Horizon's own release builds are made. Finished builds stay here to download.

New build

A Nightly's source is kept for good, so old ones can be rebuilt.

Selected .hnmod bundles are compiled into the client. Horizon pins and hook API requirements are checked before building.

Use a fine-grained token limited to this repository with Actions and Contents read/write. It stays in this tab's memory and is sent only to api.github.com. Downloading needs none.
