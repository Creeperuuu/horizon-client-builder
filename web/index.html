The program on its own can't start: it needs a version folder's game files. In the Horizon launcher, import it as a build (Versions page) and it plays with the files of a release or Nightly you already have. Native mods aren't sandboxed: only build mods whose source you trust. Mods with an [api] crate or post-build steps aren't supported yet (a build names them and stops). Builds are unsigned; compare the download with SHA256SUMS on its release page.
