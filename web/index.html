Horizon Client Builder

Compile the Horizon Minecraft client for desktop platforms, with your own .hnmod native mods compiled straight into the executable. Builds run on GitHub Actions.

1 · GitHub token

Your token is kept in this browser tab's memory only — never saved, never logged, and sent exclusively to api.github.com over HTTPS. It is used to upload your mods, start the build, and fetch the finished executable, then it is gone when you close the tab.
Needed scopes on the target repo: Actions: read+write, Contents: read+write, Metadata: read (fine-grained) or repo (classic).

2 · Build settings

Mixed-revision mods: every .hnmod pins the Horizon commit it was written for. The builder probes each mod's pin (newest commit first), then your preferred source as the last candidate, and builds at the first commit where all mods' hooks still apply — mods written for different Horizon revisions are combined automatically, no settings needed.

3 · .hnmod native mods (optional)

Drop .hnmod files here or click to browse — up to 10 files, 40 MiB each
Mods are committed to a temporary public branch while the build runs (deleted right after), and native mods are unsandboxed Rust compiled into your client — only build mods you trust.

4 · Build

How this works, retention & limits
  • Flow: your token uploads the .hnmod files to a temporary builder-upload-… branch, dispatches the Build Horizon client workflow, watches it, then downloads the horizon-client-<platform> artifact. The upload branch is deleted by the workflow itself.
  • Retention: built clients (artifacts) are deleted by a scheduled sweep about 1 hour after the build; completed build/cleanup run history after 24 hours; abandoned upload branches after 6 hours. Download promptly.
  • Mods: up to 10 .hnmod files, 40 MiB each. All mods are applied together into one build — duplicate mod IDs or conflicting hooks fail the build. Mods pinning different Horizon revisions are reconciled automatically: the workflow probes each mod's pinned commit (newest first), then the requested source, and builds at the first revision where all mods' hooks still apply.
  • First build per platform is slow (cold cargo cache, ~1–2 h); repeat builds with the same Horizon commit reuse the cache and are much quicker.
  • Privacy: no analytics, no server of its own — this is a static page; every request goes from your browser to api.github.com with your token. Closing the tab forgets everything.
